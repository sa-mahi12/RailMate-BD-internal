- `NetworkError(message, {isTimeout})` / `EmptyResult(message)` — distinct
  exceptions; timeout is never conflated with empty.

  destinationId, date}) }` — injectable; fake in tests.

  ordered by name; trips filtered by route + `active == true` + day range
  on `departure_at` (`[dayStart, dayStart+1d)`), ordered by departure;
  zero rows throw `EmptyResult`. Coordinator wiring documented in-file:
  `SupabaseSearchApi(Supabase.instance.client)` (anon key only, no secrets).
  `import supabase_flutter` used here only (dependency already in pubspec).
- `SearchState extends ChangeNotifier` — `idle/loading/loaded/empty-aware/
  error`; `errorKind: none/network/timeout`; holds stations, origin,
  destination, explicit `selectedDate` (defaults to today's calendar date
  and is always displayed); `loadStations/selectOrigin/selectDestination/
  swapEndpoints/selectDate/validateSelection (origin != destination, date
  not past)/search/retry`.

  ref-1 Home: greeting header, From/To dropdowns + swap, journey date +
