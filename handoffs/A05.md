## Deliberate design choice (extend, not replace)

Kept the existing `book_trip_service` signature (service-role-only, explicit `p_user_id` from JWT-verified Edge caller) instead of adding the packet's example `book_trip_seats(... auth.uid() ...)` SECURITY DEFINER variant, because: (a) reviewed design (`architecture/ATOMIC_BOOKING.md`, `architecture/BOOKING_EDGE_FUNCTION_PSEUDOCODE.md`) mandates service-role-only RPC with no EXECUTE grant to anon/authenticated — a DEFINER variant would open a second privileged path to every authenticated client; (b) schema keys idempotency as `request_id uuid unique(user_id, request_id)`, so a text key needs a schema change (out of scope); (c) schema status enum has no pending-payment — simulate-failure never reaches the RPC. Documented in the migration header.
