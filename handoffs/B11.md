## New/changed interfaces

- `enum RewriteStatus { idle, loading, ready, error }`.
- `RewriteState({required String draft}) extends ChangeNotifier`
  - `draft` getter, `updateDraft(String)`, `consent` (bool, single-use per-request checkbox state), `setConsent(bool)`, `status`, `suggestion` (non-null only when `ready`), `errorMessage` (non-null only when `error`), `isLoading`, `hasSuggestion`.
  - `Future<void> improve({required ReadRewriteKey readKey, required SendRewrite send})` — consent gate → draft gate → key read (absent key = setup-prompt error, `send` never called) → `send` → `ready` / mapped `error`. `consent` reset to false after every attempt. No-op while loading.
  - `String? accept()` — returns the suggestion for the caller callback, then clears local state. NEVER writes anywhere itself (no storage/post/network). Returns null when nothing to accept.
  - `void reject()` — discards suggestion, resets to `idle`, no callback, no write.
  - Error mapping (`mapRewriteError`): 401 → `'AI rewrite failed: key invalid.'`, 429 → `'AI rewrite failed: quota exceeded, try later.'`, network (Socket/Client/Http/timeout shapes) → `'AI rewrite failed: connection failed.'`, unknown → `'AI rewrite failed. Try again later.'`. `RewriteRequestException(message, {statusCode})` carries codes from future real backends; message sniffing covers backends that only throw text.
- `RewriteHostCallbacks({required ValueChanged<String> onAccepted})` — host-owned; slice never applies text, host decides.
- `RewriteBar({required ByokVault vault, required RewriteHostCallbacks callbacks, required String initialDraft, OpenRouterClientStub client = const …})` — explicit 'Improve Wording' button + per-request consent checkbox (exact B10 label `'Send my key with this request only'`, single-use reset); no-key state = disabled button + `'AI rewrite needs a key. Add one in AI Settings.'`; suggestion card with Accept/Reject + `'Nothing is replaced until you tap Accept.'`; error text rendering. Vault key is read ONLY inside the Improve tap handler and passed explicitly to `client.sendWithKey(key: key, messages: [system, user(draft)])`. Suggestion-card buttons use B11 contract labels Accept/Reject (ref-8 shows 'Use This Version / Keep Original' — I01 may relabel, semantics identical).
- **Exact launch helper signature for I01** (in `rewrite_launcher.dart`):
  ```dart
  Future<void> launchRewrite(
    BuildContext context, {
    required ByokVault vault,
    required String initialDraft,
    required ValueChanged<String> onAccepted,
    OpenRouterClientStub client = const OpenRouterClientStub(),
  })
  ```
  Shows `RewriteBar` in a scroll-controlled modal bottom sheet; on Accept it forwards the suggestion to `onAccepted` and pops the sheet; on Reject the draft is untouched. Host example: `await launchRewrite(context, vault: ByokVault(backend: SecureStorageBackend(), accountId: uid), initialDraft: _bodyController.text, onAccepted: (s) => _bodyController.text = s);`

## Proposed focused unit test (NOT placed under `test/` per packet — coordinator/test owner to add)

Fake backend (injected typedefs, no device keystore, no network): accept returns text + clears state, reject discards, 401/429 mapping, no-key initial state, consent gate, single-use consent reset.

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:railmate_bd/features/ai/rewrite/rewrite_state.dart';

void main() {
  RewriteState stateWith({String draft = 'hello world'}) =>
      RewriteState(draft: draft);

  test('accept returns text and clears state, writes nothing', () async {
    final s = stateWith();
    s.setConsent(true);
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async {
        expect(key, 'user-key');
        return 'polished $draft';
      },
    );
    expect(s.status, RewriteStatus.ready);
    expect(s.suggestion, 'polished hello world');
    final out = s.accept();
    expect(out, 'polished hello world');
    expect(s.status, RewriteStatus.idle);
    expect(s.suggestion, isNull);
    expect(s.errorMessage, isNull);
  });

  test('reject discards suggestion without callback side effects', () async {
    final s = stateWith();
    s.setConsent(true);
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async => 'better',
    );
    expect(s.hasSuggestion, isTrue);
    s.reject();
    expect(s.status, RewriteStatus.idle);
    expect(s.suggestion, isNull);
    expect(s.accept(), isNull); // nothing left to accept
  });

  test('401 maps to key invalid', () async {
    final s = stateWith();
    s.setConsent(true);
    await s.improve(
      readKey: () async => 'bad-key',
      send: ({required String key, required String draft}) async {
        throw const RewriteRequestException('unauthorized', statusCode: 401);
      },
    );
    expect(s.status, RewriteStatus.error);
    expect(s.errorMessage, contains('key invalid'));
    expect(s.suggestion, isNull);
  });

  test('429 maps to quota exceeded', () async {
    final s = stateWith();
    s.setConsent(true);
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async {
        throw const RewriteRequestException('slow down', statusCode: 429);
      },
    );
    expect(s.status, RewriteStatus.error);
    expect(s.errorMessage, contains('quota exceeded, try later'));
  });

  test('no-key initial state never calls send (core works without key)',
      () async {
    final s = stateWith();
    var sendCalled = false;
    s.setConsent(true);
    await s.improve(
      readKey: () async => null,
      send: ({required String key, required String draft}) async {
        sendCalled = true;
        return 'unreachable';
      },
    );
    expect(sendCalled, isFalse);
    expect(s.status, RewriteStatus.error);
    expect(s.errorMessage, contains('AI Settings'));
  });

  test('no consent means no send', () async {
    final s = stateWith();
    var sendCalled = false;
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async {
        sendCalled = true;
        return 'unreachable';
      },
    );
    expect(sendCalled, isFalse);
    expect(s.status, RewriteStatus.error);
  });

  test('consent is single-use: second improve needs a fresh tick', () async {
    final s = stateWith();
    s.setConsent(true);
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async => 'v1',
    );
    expect(s.consent, isFalse);
    var sendCalled = false;
    await s.improve(
      readKey: () async => 'user-key',
      send: ({required String key, required String draft}) async {
        sendCalled = true;
        return 'v2';
      },
    );
    expect(sendCalled, isFalse); // consent was consumed by the first request
  });
}
```
