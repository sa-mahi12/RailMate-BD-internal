## New/changed interfaces

- `Comment` — `minBodyLength = 1`, `maxBodyLength = 500` (trimmed); fields `id/postId/userId/body/createdAt`; `validateBody(String?) → String?`; `Comment.draft({postId, userId, body})` (throws `ArgumentError` on blank ids / invalid body, stores trimmed body); `Comment.fromMap(Map)` (parses `post_id/user_id/body/created_at`); `toInsertMap()` (`post_id/user_id/body`, server sets id/created_at)
- `FetchComments = Future<List<Comment>> ({required postId})`; `AddCommentRow = Future<Comment> ({required postId, userId, body})`; `DeleteCommentRow = Future<void> (String commentId)`
- `CommentThread({required postId, required fetchComments})` — `status/errorMessage/mutationError/adding/deletingIds/comments`; `load()` (keeps only rows with matching `postId`); `add({userId, body, addRow})` (validates 1..500 first, rejects cross-post echo with `StateError`, merges via `applyRealtimeInsert`); `remove(commentId, deleteRow)` (per-row guard, keeps row on injected failure); `applyRealtimeInsert(Comment) → bool` (false on foreign post or duplicate id; newest-first `(created_at, id)` insert); `applyRealtimeDelete(String) → bool` (false when absent)
- `CommentEventKind { insert, delete }`; `CommentRealtimeEvent({eventId, kind, comment, commentId})` (empty `eventId` dropped; `rowId` getter)
- `CommentRealtimeSubscription` — `lastEventId/isSubscribed/isDisposed/seenEventCount`; `subscribe({stream, onEvent})` (replaces attachment, drops empty/repeat ids); `unsubscribe()` (idempotent); `reconnect({streamFactory(lastEventId), onEvent})` (replay-safe via seen-set); `dispose()` (permanent; later `subscribe`/`reconnect` throw `StateError`; listener cancelled so no events after dispose)
- `PageCursor({createdAt, id})`; `CursorPage<T>({rows, nextCursor, hasMore})` + `isEmpty`
- `FetchCursorPage<T> = Future<List<T>> ({required limit, PageCursor? before})`; `IdOf<T>` / `CreatedAtOf<T>` extractors
- `CursorPaginator<T>({fetchPage, idOf, createdAtOf})` — `static pageSize = 5`; `status/errorMessage/rows/cursor/hasMore/seenCount`; `loadFirst()` (full reset + newest window); `loadNext()` (no-op while loading or when `!hasMore`); `insertRealtime(T) → bool` (false on already-seen non-empty id; null/empty ids always inserted front); `reset()`; short window (`raw.length < pageSize`) sets `hasMore = false`; anchor = last raw row with both timestamp + non-empty id (no anchorable row → cursor unchanged, never loops on duplicates)
