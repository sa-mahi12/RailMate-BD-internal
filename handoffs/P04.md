## Motion (P01 primitives only, reduced-motion branched)
- Copy entrances: `StaggeredColumn` (FadeSlideIn, 40 ms stagger, y12) — applied only to the current page, so entrances play once per page and never replay on rebuild (matrix rule).
- Hero: small parallax (`Transform.translate` 28 px + up to 4 % scale) and crossfade driven by continuous `ScrollNotification` page position — no decorative loops.
- Page indicator: `AnimatedContainer` width 8→24 px + colour tween, 220 ms `AppMotion.standard`, `emphasized` curve.
- Skip fade 140 ms; Next/Get Started page change 320 ms `AppMotion.medium` `emphasized`.
- **Reduced motion** (`ReducedMotion.isReduced`): no parallax, no stagger wrappers, hero uses plain `Opacity` instead of `AnimatedOpacity`, Skip uses `Offstage` instead of a fade, dot tween duration collapses to `Duration.zero`. Verified by test (`find.byType(AnimatedOpacity)` findsNothing after a single pump).
