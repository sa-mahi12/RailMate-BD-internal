# Coordinator route and two free implementation models

The user's requested roles are **different credentials and providers**: the main OpenCode coordinator uses AgentRouter DeepSeek from the owner's provider account; independent workers use OpenCode-provided free MiMo and Muse. The app's optional OpenRouter API is user-supplied and entirely separate. Do not put an OpenRouter app key in the coordinator config or an AgentRouter developer key in the APK.

Check actual CLI `opencode --version`, `opencode models opencode`, `opencode models agentrouter`, and `opencode run --help`; record exact observed model IDs. The current v2 provider template uses `providers`, `env`, `package` and `settings.baseURL`, unlike older OpenCode examples that use singular `provider` and `options.baseURL`. Do not mix incompatible variants. The AgentRouter official integration page was not accessible in the research environment (WAF); the base URL and offered DeepSeek model must come from the owner-visible official instructions or authenticated dashboard. Do not install a community proxy by default, nor hardcode a third-party npm server's credential source.

1. Put provider credential in private environment or OpenCode auth UI, not in Git/source. A shell env variable is inherited by launched OpenCode subprocesses; workers should not receive the AgentRouter credential unless required. Prefer separate worker process environment that omits unused provider secrets, then smoke-test.
2. Merge only the verified provider section into the private global OpenCode config after backing it up; do not replace the user's existing FindBack configuration. Validate JSONC/schema and list models again.
3. Select coordinator's actual `agentrouter/<verified-model-id>`. Run a single short and cheap prompt and record sanitized outcome, rate limit and model name. If the model cannot tool-call or doesn't follow packet constraints, stop and use owner-selected verified alternative; don't claim it worked.
4. Verify both free worker model IDs and actually launch distinct OpenCode sessions. Model listing is not proof that requests are free/available or that session compaction succeeds; run one authorized minimal response and resume each ID once. Monitor usage so free quota exhaustion stops work, rather than paid fallback.
5. Configure auto compaction in v2 as `auto`, `keep.tokens`, `buffer` only if local schema confirms. Save private checkpoint before manual `/compact` and after each packet; compare source state on resume. Never trust generated session summary to replace owner contract or commit SHA.
